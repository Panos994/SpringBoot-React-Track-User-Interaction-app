# Spring Boot & React - Track User Interaction App  

## Overview  
This application tracks **user interactions** and stores event data in an **SQLite database**. Events include button clicks, mouse coordinates, timestamps, and more. The frontend is built with **React**, while the backend is developed using **Spring Boot**.  

## Features  
- **Tracks User Interactions:**  
  - Button clicks  
  - Mouse movements (coordinates)  
  - Timestamps of interactions  
- **Stores Data in SQLite:** Persistent event logging for analysis.  
- **REST API with Spring Boot:** Backend handles requests and stores interaction data.  
- **React Frontend:** Displays UI and sends interaction data to the backend.  

## Tech Stack  
- **Frontend:** React, JavaScript  
- **Backend:** Spring Boot, Java  
- **Database:** SQLite  
- **API Communication:** RESTful APIs
